# Examples

| File | What it is |
|---|---|
| `style.example.json` | A complete edit style: talking head + voice-over + screen recording, tight cuts, two-line highlighted captions. Keys starting with `_` are comments. |
| `plan.json` | A timeline plan: camera part 1, the voice-over, then the rest of the camera. Used by `subtitles.py build --plan`. |
| `subtitle-rules.json` | Subtitle rule overrides: 3–4 words in two lines, uppercase, keyword and number highlights. |
| `positions.json` | Subtitle position per zone for a 1080×1920 comp, used by `subtitles.py ae-expr --positions`. |
